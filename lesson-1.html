What is a website?

A website is a set of files that a browser (like Chrome or Safari) downloads and shows on your screen. Those files live on a server, a computer that is always online and sends the files whenever someone visits the address.

Almost every website is built with three languages, and each one has its own job. Think of building a house:

  • HTML is the structure: the walls, rooms and doors. It says "this is a heading, this is a paragraph, this is a picture."
  • CSS is the paint and decoration: colors, fonts, spacing and layout.
  • JavaScript is the electricity: it makes things move and respond, like buttons, menus and forms.

In this course you'll learn HTML and CSS. JavaScript comes in course 03.
