Links and images

Links are what make the web a "web." They use the <a> tag (short for "anchor"). The href attribute holds the address to go to, and the text between the tags is what people tap.

An attribute is extra information inside an opening tag, written as name="value". Adding target="_blank" opens the link in a new tab.

Images use <img>. It has no closing tag. The src attribute is the image file, and alt is a short text description.

Always write good alt text. People who use screen readers hear it, and it shows up if the image fails to load on a slow connection.

<a href="https://www.wikipedia.org">Visit Wikipedia</a>

<img src="logo.svg" alt="GrayBrackets logo" width="80">
Tip: Ilarawan ang larawan. Good alt text says what the picture shows, like "Jeepney parked in front of the store," not just "image."
