Lists and tables

Lists group related items. Use <ul> (unordered list) for bullet points where the order doesn't matter, and <ol> (ordered list) for numbered steps. Each item goes inside <li>.

Tables show data in rows and columns, like a price list. A table is built from <table>, rows with <tr>, header cells with <th>, and regular cells with <td>.

Use tables only for real data. For page layout (putting things side by side), you'll use CSS instead.

<h2>Shopping list</h2>
<ul>
  <li>Rice</li>
  <li>Eggs</li>
</ul>

<h2>Price list</h2>
<table>
  <tr><th>Item</th><th>Price</th></tr>
  <tr><td>Pandesal</td><td>₱3</td></tr>
  <tr><td>Coffee</td><td>₱15</td></tr>
</table>
Tip: Listahan para sa listahan, table para sa data. A shopping list is a list; a price list with columns is a table.
