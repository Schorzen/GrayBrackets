Intro to CSS

HTML builds the structure; CSS makes it look good. A CSS rule has a selector (what to style) and declarations (how to style it), each a property and a value.

For example, h1 { color: navy; } makes every <h1> navy. The selector is h1, the property is color, and the value is navy.

To style only some elements, give them a class in HTML, like <p class="sale">, and select it in CSS with a dot: .sale.

For now you can put CSS inside a <style> tag. In real projects, it usually goes in its own file, like this site's styles.css.

h1 {
  color: navy;
  font-size: 32px;
}

.sale {
  background-color: gold;
  padding: 8px;
  border-radius: 6px;
}
Tip: Subukan mo lang. Change one value at a time and tap Run code. Experimenting is the fastest way to learn CSS.
